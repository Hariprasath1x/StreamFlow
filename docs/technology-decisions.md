# Technology Decisions

- **Python (3.12):** Chosen as the core scripting language for its wide adoption in Data Engineering and compatibility with PySpark and Airflow.
- **Faker:** Generates realistic testing data easily without external dependencies.
- **Apache Kafka:** Industry-standard distributed event streaming platform, useful for showcasing real-time data handling.
- **Apache Spark (PySpark):** A powerful data processing engine, used here to demonstrate knowledge of distributed computing concepts.
- **PostgreSQL:** Reliable, easy-to-deploy relational database used to mock a data warehouse.
- **Apache Airflow:** Used to demonstrate knowledge of modern data orchestration.
- **Docker/Docker Compose:** Used to isolate complex infrastructure (Kafka, PostgreSQL, Airflow) from the local machine for easy setup and teardown.
- **Power BI:** Widely used BI tool that connects easily to PostgreSQL for demonstrating end-to-end data value.
